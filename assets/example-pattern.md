# harbor-dusk: checker only

Written by the person who studied the made-up references behind `example-card.json`. Never hand this file
to whoever makes the new work; it is for `style.py lint --pattern` and `style.py review`.

## Signatures

- A lighthouse beam sweeping across the frame as the transition between scenes.
- Captions set inside a thin rectangular frame, like a ship's brass nameplate, centred low in the frame.
- A foghorn note under every title card.

## Set pieces and order

- The parcel van driving along the harbour wall at dusk.
- Both films run: harbour wide, a worker's hands, the parcel, the van leaving, the name over black.
